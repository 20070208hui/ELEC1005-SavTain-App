## ELEC1005-SavTain-App

A Power Apps prototype designed to help rescuers in mountain areas to manage rescue operations, view weather conditions, and access rescue location information.


# Project Summary

Mountain rescue operations require quick access to rescue information in high-pressure situations.

The system helps rescuers:

* View rescue tasks
* Submit incident reports
* Check weather conditions
* Access rescue locations
* Receive equipment recommendations


# Key Features

* Dynamic rescue task gallery
* Accept/reject rescue operations
* Weather updates based on rescue location
* Map page with rescue locations
* Incident report submission
* Equipment recommendations
* User login, signup, and profile page for logout


## Quick Start

1. Open the Power Apps prototype
2. Log in using a registered account (or create a new account by clicking join us)
3. Open the Home Page
4. Accept a rescue task
5. Open the Weather Page to view weather conditions and recommended equipment
6. Open the Map Page to view the rescue location information
7. Submit incident reports if required
8. Log out of the App


## Common Confusion

# “Why does the weather page only show the current local weather?”

Weather information changes based on the accepted rescue task. Users must accept a task on the Home Page first. If no rescue task is active, the Weather Page only displays the user’s current laocal weather

# “Why does the map only show my location?”

Rescue location information on the Map Page changes based on the accepted rescue task. If no rescue task is active, the Map Page only displays the user’s current location.

# “Why can’t I submit the incident report?”

All required fields must be completed before submitting the report.
